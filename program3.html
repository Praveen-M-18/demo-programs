03. Web-Based Feedback System using PHP and MySQL

Submit feedback, store it in a MySQL database, and view submitted feedback records.

index.php 
<?php
include("db.php");

if(isset($_POST['submit']))
{
    $name = $_POST['name'];
    $email = $_POST['email'];
    $message = $_POST['message'];

    $sql = "INSERT INTO feedback(name,email,message)
            VALUES('$name','$email','$message')";

    if(mysqli_query($conn, $sql))
    {
        echo "Feedback Submitted Successfully";
    }
    else
    {
        echo "Feedback Not Submitted";
    }
}
?>

<!DOCTYPE html>
<html>
<head>
    <title>Feedback System</title>
</head>
<body>

<h2>Feedback Form</h2>

<form method="post">
    Name<br>
    <input type="text" name="name" required><br><br>

    Email<br>
    <input type="email" name="email" required><br><br>

    Feedback<br>
    <textarea name="message" rows="5" cols="30"
        required></textarea><br><br>

    <input type="submit" name="submit" value="Submit">
</form>

<br>
<a href="view.php">View Feedback</a>

</body>
</html>
db.php 
<?php
$servername = "localhost";
$username = "root";
$password = "";
$database = "feedbackdb";

$conn = mysqli_connect(
    $servername,
    $username,
    $password,
    $database
);

if (!$conn) {
    die("Connection failed: " . mysqli_connect_error());
}
?>
view.php 
<?php
include("db.php");
?>

<!DOCTYPE html>
<html>
<head>
    <title>View Feedback</title>
</head>
<body>

<h2>Feedback Details</h2>

<table border="1">
<tr>
    <th>ID</th>
    <th>Name</th>
    <th>Email</th>
    <th>Message</th>
</tr>

<?php
$sql = "SELECT * FROM feedback";
$result = mysqli_query($conn, $sql);

while ($row = mysqli_fetch_assoc($result))
{
?>
<tr>
    <td><?php echo $row['id']; ?></td>
    <td><?php echo $row['name']; ?></td>
    <td><?php echo $row['email']; ?></td>
    <td><?php echo $row['message']; ?></td>
</tr>
<?php
}
?>

</table>

<br>
<a href="index.php">Back</a>

</body>
</html>

📝 Important Notes — How to Run

1. Start XAMPP

  • Open the XAMPP Control Panel.
  • Click Start for Apache and MySQL.
  • Make sure both services start successfully.

2. Create the project folder

  • Go to C:\xampp\htdocs.
  • Create a folder named FeedbackSystem.
  • Inside it, create index.php, db.php, and view.php.
  • Copy the corresponding code into each file.

3. Create the database and table

  • Open http://localhost/phpmyadmin in your browser.
  • Click the SQL tab and execute the following SQL commands.
SQL — Run in phpMyAdmin 
CREATE DATABASE feedbackdb;

USE feedbackdb;

CREATE TABLE feedback (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL,
    message TEXT NOT NULL
);

4. Run the program

  • Keep Apache and MySQL running in XAMPP.
  • Open http://localhost/FeedbackSystem/index.php.
  • Enter your name, email, and feedback, then click Submit.
  • Open the View Feedback link to see saved records.

5. Important reminders

  • Save all three files with the .php extension.
  • The database name in db.php must match feedbackdb.
  • MySQL must be running because the program stores and retrieves feedback from the database.
  • The supplied SQL in index.php uses direct string interpolation and is vulnerable to SQL injection. For real applications, use prepared statements and escape output before displaying stored feedback.
  • The db.php above intentionally contains only the database connection; it avoids printing HTML every time another PHP page includes it.
