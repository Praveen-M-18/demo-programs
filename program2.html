02. Electricity Bill Calculation using PHP

Calculates electricity charges based on units consumed and displays a bill.

electricity.php 
<?php
// Initialize variables
$show_bill = false;
$name = "";
$units = "";
$energy_charges = 0;
$fixed_charges = 50.00;
$total_amount = 0;

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $name = htmlspecialchars($_POST['consumer_name']);
    $units = (int)$_POST['units'];

    // Calculation Logic
    // First 100 units @ ₹ 2.50
    // Remaining units @ ₹ 3.50
    if ($units <= 100) {
        $energy_charges = $units * 2.50;
    } else {
        $energy_charges = (100 * 2.50) + (($units - 100) * 3.50);
    }

    $total_amount = $energy_charges + $fixed_charges;
    $show_bill = true;
}

📝 Important Notes — How to Run

1. Start XAMPP

  • Open the XAMPP Control Panel.
  • Click Start next to apache
  • Make sure Apache starts successfully.

2. Save the PHP file

  • Open the XAMPP installation directory.
  • Go to the htdocs folder, usually C:\xampp\htdocs on Windows.
  • Create a folder named ElectricityBill.
  • Save the copied code inside it as electricity.php.

3. Run the program

  • Open Chrome or another web browser.
  • Enter http://localhost/ElectricityBill/electricity.php in the address bar.
  • Enter a consumer name and the number of units consumed.
  • Click Generate Bill to display the electricity bill.
