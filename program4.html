04. User Login using PHP and MySQL

A basic login system with session management, a protected dashboard, and logout functionality.

index.php 
<?php
session_start();
include("db.php");

$error = "";

if (isset($_POST["login"])) {
    $username = $_POST["username"];
    $password = $_POST["password"];

    $sql = "SELECT * FROM logtbl WHERE username = ? AND password = ?";
    $stmt = mysqli_prepare($conn, $sql);

    mysqli_stmt_bind_param($stmt, "ss", $username, $password);
    mysqli_stmt_execute($stmt);

    $result = mysqli_stmt_get_result($stmt);

    if (mysqli_num_rows($result) == 1) {
        $_SESSION["username"] = $username;
        header("Location: dashboard.php");
        exit();
    } else {
        $error = "Invalid username or password";
    }

    mysqli_stmt_close($stmt);
}
?>

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Login Form</title>
</head>
<body>

<h2>User Login</h2>

<?php if ($error !== ""): ?>
    <p><?php echo htmlspecialchars($error); ?></p>
<?php endif; ?>

<form method="post">
    <label for="username">Username:</label>
    <input type="text" id="username" name="username" required>

    <br><br>

    <label for="password">Password:</label>
    <input type="password" id="password" name="password" required>

    <br><br>

    <input type="submit" name="login" value="Login">
</form>

</body>
</html>
db.php 
<?php
$servername = "localhost";
$username = "root";
$password = "";
$dbname = "pro4";

$conn = mysqli_connect(
    $servername,
    $username,
    $password,
    $dbname
);

if (!$conn) {
    die("Database connection failed: " . mysqli_connect_error());
}
?>
dashboard.php 
<?php
session_start();

if (!isset($_SESSION["username"])) {
    header("Location: index.php");
    exit();
}
?>

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Dashboard</title>
</head>
<body>

    <h1>Dashboard Page</h1>

    <p>Welcome,
        <?php echo htmlspecialchars($_SESSION["username"]); ?>
    </p>

    <br>

    <a href="logout.php">Logout</a>

</body>
</html>
logout.php 
<?php
session_start();

$_SESSION = [];
session_destroy();

header("Location: index.php");
exit();
?>

📝 Important Notes — How to Run

1. Start XAMPP

  • Open the XAMPP Control Panel.
  • Click Start for Apache and MySQL.
  • Make sure both services are running.

2. Create the project folder

  • Open C:\xampp\htdocs.
  • Create a folder named LoginSystem.
  • Save all four PHP files inside that folder.

3. Create the database and table

  • Open http://localhost/phpmyadmin.
  • Choose the SQL tab and execute these commands.
SQL — Run in phpMyAdmin 
CREATE DATABASE pro4;

USE pro4;

CREATE TABLE logtbl (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL
);

INSERT INTO logtbl (username, password)
VALUES ('student', '1234');

4. Run the login system

  • Keep Apache and MySQL running.
  • Open http://localhost/LoginSystem/index.php.
  • Enter the test credentials below.
  • Click Login. The dashboard should display the username.
  • Click Logout to return to the login page.

5. Test login credentials

  • Username: student
  • Password: 1234

6. Important reminders

  • Use the exact database name pro4 and table name logtbl.
  • Do not add HTML or echo output before the redirect headers in PHP files.
  • session_start() must run before accessing session variables.
  • The dashboard checks whether a user session exists before displaying its content.
  • This lab example stores plain-text passwords for simplicity. Real applications should store password hashes using password_hash() and verify them using password_verify().
  • The login query uses a prepared statement to help prevent SQL injection.
