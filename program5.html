05. File Handling using Node.js

Creates a text file, writes employee information, and reads the file using Node.js.

app.js 
const fs = require("fs");

const filename = "sample.txt";

const data = `
Employee Name: Batman
Employee ID: 12345
`;

fs.writeFile(filename, data, function (err) {
  if (err) {
    console.log(err);
  } else {
    console.log("File created");

    fs.readFile(filename, function (err, content) {
      if (err) {
        console.log(err);
      } else {
        console.log(content);
      }
    });
  }
  console.log(data);
});

📝 Important Notes — How to Run

1. Install Node.js

  • Node is needed to run this program
  • Check the installation by running these commands.
  • Download and install Node.js from https://nodejs.org/ if it is not already installed.
Terminal commands 
node -v
npm -v

2. Create the project

  • Create a folder named FileHandling.
  • Open the folder in VS Code or navigate to it using the terminal.
  • Create a file named app.js and paste the program code into it.
  • No external packages are required because fs is a built-in Node.js module.

3. Run the program

  • Open a terminal in the project folder.
  • Execute the following command.
Run command 
node app.js

4. Expected output

Console output (illustrative) 
File created

Employee Name: Batman
Employee ID: 12345

[Buffer containing the file contents]
  • The exact output order may vary because the file operations use asynchronous callbacks.
  • fs.writeFile() creates the file and writes the employee details.
  • fs.readFile() reads the file after writing completes.
  • The file sample.txt is created in the current working directory from which you run the command.
  • The read operation returns a Buffer by default. To display readable text instead, use fs.readFile(filename, "utf8", callback).
